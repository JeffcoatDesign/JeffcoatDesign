## Hello, I'm Jacob

I’m a Simulation Science graduate who creates games as a means of exploring the world of simulations. Notable games I have created include [Scrapscallions](https://github.com/JeffcoatDesign/Scrapscallions), [Cast-Forward](https://github.com/JeffcoatDesign/Cast-Forward), and [Ham-Fisted](https://github.com/JeffcoatDesign/Ham-Fisted-2.0).

You can view my [simulation portfolio here](https://jeffcoatdesign.github.io/Portfolio/) or my [games portfolio here](https://jeffcoatdesign.github.io/MyGames/).

### Tools
My primary coding languages are: C#, C++, C, Python, PHP, SQL, HTML, and JavaScript. My main tools are: Visual Studio, Unity, Maya, Houdini, and Photoshop.

### What I Built
I have built a multitude of projects which include:
- [Scrapscallions](https://github.com/JeffcoatDesign/Scrapscallions), a robot-battling game where I implemented Goal-Oriented Action Planning to make smarter in-game agents.
- [Cast-Forward](https://github.com/JeffcoatDesign/Cast-Forward), my biggeset dive into procedural generation that depends on graph generation, triangulation, and shape grammars.
- [Ham-Fisted](https://github.com/JeffcoatDesign/Ham-Fisted-2.0), a split-screen multiplayer game that I demonstated at the 2023 Game Developers Conference expo.
- [Horse Meadow](https://github.com/JeffcoatDesign/HorseMeadow), a project that used SQL to manage user logins and inventories when trading digital horses.
- [Equipped](https://github.com/JeffcoatDesign/Equipped), a project where I extended multiple systems in multiplayer to include character customization, a simple inventory, and a variety of items.
- [Sprite Quest](https://github.com/JeffcoatDesign/Sprite_Quest), a 360° adventure that we built in Unity.
- [VR Climbing](https://github.com/JeffcoatDesign/VR_Climbing) a difficult climbing game made with VR.
